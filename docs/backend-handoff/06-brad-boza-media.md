# 06 — براد مع بوظة: عنوان الأسعار من الـAPI (بدون صورة كاسة)

**الأولوية:** منخفضة  
**Endpoint:** `GET /menu/products/brad-boza`  
**تاريخ:** 2026-08-11

---

## قرار المنتج

صفحة `/menu/order/brad-boza` تعرض **صورة المنتج الواحدة** فقط (`image`).

- **ما فيش** صورة كاسة/بوظة ثانية جنب البراد — لا في الفرونت ولا مطلوب من الباك.
- `includesIceCreamStep` تبقى للخطوة «أضف بوظة» فقط، مش لصورة إضافية.

---

## المطلوب من الباك (متبقي)

### `pricingLabel`

الـAPI حالياً يبعت مثلاً `"أسعار البراد"`. الفرونت ما عاد يضيف «أسعار» فوقها.

- إما العنوان الكامل: `"أسعار البراد"`  
- أو الاسم فقط: `"البراد"` (الفرونت يضيف «أسعار» إذا ناقصة)

```json
{
  "slug": "brad-boza",
  "image": "https://host/storage/products/brad-boza.png",
  "includesIceCreamStep": true,
  "pricingLabel": "أسعار البراد",
  "name": "براد مع بوظة",
  "description": "براد منعش مع كرات البوظة بنكهتك المفضلة"
}
```

---

## معايير قبول

- [ ] صفحة البراد تعرض صورة واحدة من `image` فقط
- [ ] عنوان الجدول = نص الـAPI مرة واحدة (مش «أسعار أسعار البراد»)
- [ ] **لا** حقل `secondaryImage` ولا صورة كاسة ثابتة في الفرونت
