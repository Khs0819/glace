## أ) صور حقيقية بدل placeholders — المنيو

### تم ✓

- صور **المنتجات** (`product.image`) للـ19 منتج اترفعت وصارت مسارات storage حقيقية  
  مثال: `"image": "products/01KZRJZSATG4EGJED63Q6HD2HP.png"`  
  (بعد بند URL الكامل في 04، لازم تصير روابط مطلقة)

### لسه ناقص

| المكان | المطلوب |
|---|---|
| `flavors[].image` | روابط حقيقية / storage — كثيرها لسه `cdn.example.com` |
| `items[].image` | شوف [`01-items-image.md`](./01-items-image.md) |

**ممنوع:** `example.com` / `cdn.example.com`.

## ب) فلترة التصنيف

- البراميتر الصحيح: `?category=`
- لو وصل `?categoryId=` بالغلط: **ارفض بـ422** أو تجاهل بوضوح — لا ترجع كل المنتجات بصمت وكأنها فلترة ناجحة.
