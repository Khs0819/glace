# مواعيد العمل — المتجر والتوصيل

**التاريخ:** 2026-09-17

## ما يتحكم بالحالة

1. **الجدول الأسبوعي** — لكل يوم: يعمل/لا يعمل، ساعة فتح، ساعة إغلاق. جدول للمتجر وجدول مستقل للتوصيل.
   - نفس الساعة في «من» و«إلى» = 24 ساعة.
   - ساعة إغلاق أصغر من الفتح = الدوام يمتد لبعد منتصف الليل (مثال: 14:00 ← 02:00).
2. **الاستثناء اليدوي** — المدير فقط يفتح أو يغلق خارج الجدول، لمدة محددة ثم يعود للجدول تلقائياً:
   حتى الموعد التالي في الجدول / ساعة / ساعتان / 4 ساعات / حتى الإعادة يدوياً.

- التوصيل **لا يكون متاحاً والمتجر مغلق**.
- الساعات تُقرأ بتوقيت **Asia/Gaza** (`GLACE_TIMEZONE`)، لا بتوقيت الخادم UTC.
- قبل ضبط أي جدول، المتجر مفتوح 24 ساعة كما كان.

لوحة التحكم: **الطلبات ← إعدادات المتجر**.

## `GET /api/store/status`

لا يُخزَّن مؤقتاً (`Cache-Control: no-store`). الحقول الأربعة الأولى بقيت كما هي.

```json
{
  "storeOpen": true,
  "deliveryOpen": false,
  "closedMessage": "المتجر مغلق حالياً — نراكم قريباً!",
  "deliveryClosedMessage": "التوصيل غير متاح حالياً — يمكنك الاستلام من المحل",
  "autoConfirmMinutes": 30,
  "timezone": "Asia/Gaza",
  "serverTime": "2026-09-21T11:00:00+03:00",

  "store": {
    "open": true,
    "source": "schedule",
    "override": null,
    "scheduleOpen": true,
    "opensAt": null,
    "closesAt": "2026-09-21T23:00:00+03:00",
    "nextChangeAt": "2026-09-21T23:00:00+03:00",
    "today": { "day": "mon", "label": "الإثنين", "enabled": true, "open": "10:00", "close": "23:00", "allDay": false }
  },

  "delivery": {
    "open": false,
    "source": "schedule",
    "override": null,
    "scheduleOpen": false,
    "opensAt": "2026-09-21T12:00:00+03:00",
    "closesAt": null,
    "nextChangeAt": "2026-09-21T12:00:00+03:00",
    "today": { "day": "mon", "label": "الإثنين", "enabled": true, "open": "12:00", "close": "22:00", "allDay": false }
  },

  "schedule": {
    "store": [
      { "day": "sat", "label": "السبت", "enabled": true, "open": "10:00", "close": "23:00", "allDay": false },
      "… حتى الجمعة (7 عناصر، السبت أولاً)",
      { "day": "fri", "label": "الجمعة", "enabled": false, "open": null, "close": null, "allDay": false }
    ],
    "delivery": ["… نفس الشكل"]
  }
}
```

| الحقل | المعنى |
|---|---|
| `open` | الحالة الفعلية الآن — هذا ما يُعتمد عليه |
| `source` | `schedule` حسب الجدول · `override` استثناء من المدير · `store_closed` (للتوصيل فقط) مغلق لأن المتجر مغلق |
| `override` | `{ "state": "open" \| "closed", "until": ISO \| null }` — `until` فارغ = حتى يعيده المدير |
| `opensAt` / `closesAt` | متى يفتح (إن كان مغلقاً) / متى يُغلق (إن كان مفتوحاً). `null` = لا تغيير خلال الأسبوع |
| `nextChangeAt` | أقرب تغيير للحالة |
| `scheduleOpen` | ما يقوله الجدول وحده، بغض النظر عن الاستثناء |

كل الأوقات ISO 8601 بتوقيت المحل مع الإزاحة.

## الطلبات

`POST /api/orders` صار **يرفض الطلب** حسب الحالة (قبل هذا التحديث لم يكن يفحص شيئاً):

| الحالة | الرد |
|---|---|
| المتجر مغلق | `422` — `errors.store[0]` = رسالة الإغلاق |
| التوصيل مغلق وطلب توصيل | `422` — `errors.deliveryMethod[0]` = رسالة توقف التوصيل |

الاستلام من المحل وتناول الطعام داخله يبقيان متاحين ما دام المتجر مفتوحاً.

**مقترح للفرونت:** اقرأ `/store/status` عند فتح السلة وقبل الدفع، وأخفِ خيار التوصيل حين `deliveryOpen = false`، واعرض «نفتح {opensAt}» حين يكون المتجر مغلقاً. الفحص في الخادم يبقى الحَكَم حتى لو تغيّرت الحالة بين القراءة والإرسال.
