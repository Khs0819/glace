# بوظة إضافية على الوافل والكريب

**التاريخ:** 2026-09-24 · **محدَّث:** 2026-09-30

> **تحديث 30-09:** نكهات البوظة الإضافية صارت **نفس نكهات القائمة**، لا قائمة
> ثانية تُكتب باليد. إطفاء نكهة من «القائمة ← النكهات» يُطفئها على كل منتج
> يعرضها. التفاصيل في آخر الملف.

## `GET /menu/products` و `GET /menu/products/{slug}`

حقل اختياري `extraScoop` يظهر **فقط** للمنتجات التي أعدّ لها المدير نكهات:

```json
{
  "slug": "crepe",
  "kind": "flat-list",
  "extraScoop": {
    "classic": [
      { "id": "scoop-classic-vanilla", "label": "فانيلا", "price": 5, "available": true }
    ],
    "special": [
      { "id": "scoop-special-pistachio", "label": "بيستاشيو", "price": 9, "available": true },
      { "id": "scoop-special-lotus", "label": "لوتس", "price": 8, "available": false }
    ]
  },
  "items": [ "… النكهات كما هي، بلا تغيير" ]
}
```

| الحالة في اللوحة | ما يصل الفرونت |
|---|---|
| لا نكهات لهذا المنتج | الحقل **غائب تماماً** |
| نكهة واحدة موقوفة والبقية متاحة | تبقى في القائمة بـ `available: false` |
| كل النكهات موقوفة («تعطيل الكل») | الحقل **غائب تماماً** |
| عائلة بلا نكهات | مفتاحها غائب — قد يصل `classic` وحده |

- لكل نكهة **سعرها الخاص**؛ النكهات داخل العائلة الواحدة ليست بالضرورة بنفس السعر.
- النكهات **لا تتكرر** داخل مصفوفة `addons` العادية للمنتج، حتى لا تُرسم مرتين.

## الطلب — بلا شكل جديد

تُرسل النكهة المختارة داخل `selections[]` للسطر، بنفس شكل أي إضافة:

```json
{
  "productId": "…",
  "selections": [
    { "kind": "item", "id": "nutella", "label": "نوتيلا", "qty": 1 },
    { "kind": "addon", "id": "scoop-special-pistachio", "label": "بيستاشيو", "qty": 1, "unitPrice": 9 }
  ],
  "quantity": 1
}
```

الخادم:
- **يُسعّرها من اللوحة**، ويتجاهل `unitPrice` و`addonTotal` القادمين من العميل.
- يرفض `422` إذا كان المعرّف **غير معروف**، أو **يخص منتجاً آخر**، أو **النكهة موقوفة**.
- يرفض `qty` أكبر من 1 — البوظة كرة واحدة أو لا شيء.
- تظهر في وصف الصنف وفي الفاتورة ضمن «إضافات: بيستاشيو».

«نكهة واحدة كحد أقصى من العائلتين» تبقى قاعدة واجهة كما في ملفكم؛ الخادم لا يفرضها، ولو وصلت نكهتان سُعّرت كل منهما بسعرها.

## لوحة التحكم

في صفحة المنتج تبويب **«بوظة إضافية»**، يظهر لمنتجات القائمة المسطّحة فقط (الوافل، الكريب، البان كيك، البيتزا…). المنتجات المركّبة لها خطوة بوظة أصلاً.

- **«تعطيل الكل»** يخفي الخيار كله من **هذا المنتج** دون حذف النكهات وأسعارها.
- **«تفعيل الكل»** يعيده.
- النكهات لا تظهر في تبويب «الإضافات الخاصة بالمنتج»، ولا تُدار من مكانين.

# تحديث 2026-09-30 — قائمة نكهات واحدة

## ما كان

البوظة الإضافية كانت تحمل **نكهاتها الخاصة**: اسماً وسعراً يُكتبان بخط اليد على كل منتج، بجانب قائمة النكهات الحقيقية في **القائمة ← النكهات**. قائمتان تعنيان مفتاحين: المحاسب يُغلق «بيستاشيو» حين تنفد، وتبقى معروضة على كل كريب ووافل في المحل.

## ما صار

**سطر البوظة صار يشير إلى نكهة من القائمة.** ما يبقى على المنتج هو ما يخصّ المنتج: **السعر** — فكرة البوظة على الكريب قد لا تساوي سعرها على الوافل — و**الترتيب**. أما الاسم والعائلة و**التوفر** فمن النكهة نفسها.

| المفتاح | أين | ماذا يفعل |
|---|---|---|
| **متوفرة** | «القائمة ← النكهات»، أو نفس العمود داخل تبويب البوظة | تُغلق النكهة **في كل الموقع** — كل منتج يعرضها |
| **تعطيل الكل** | تبويب «بوظة إضافية» | يُخفي خيار البوظة عن **هذا المنتج وحده**، والأسعار محفوظة |

إضافة نكهة صارت **اختياراً من القائمة** لا كتابة: العائلة والاسم يأتيان معها.

### ما يتبع النكهة تلقائياً

- **إعادة تسمية** نكهة → الاسم الجديد على كل منتج يعرضها.
- **نقلها** من كلاسيك إلى سبيشال → تنتقل بين القائمتين على صفحة المنتج.
- **إطفاؤها** → تصل الفرونت بـ`available: false` (رمادية)، والطلب بها يُرفض `422` باسمها.
- **حذفها** → السطر يبقى في اللوحة ليراه المدير («— نكهة محذوفة —»)، **ولا يُباع**.

### الـ API — بلا تغيير في الشكل

`extraScoop` كما هو: نفس المفاتيح ونفس الحقول. فقط `label` و`available` صارا يُقرآن من النكهة.

`id` **لم يتغيّر** — هو معرّف سطر الإضافة كما كان، فسلة محفوظة عند زبون تبقى صالحة، ولا يتحرّك حين تُعاد تسمية النكهة.

## الترحيل — لا يضيع شيء مما كُتب

الهجرة تربط كل سطر موجود بنكهة:

1. سطر اسمه يطابق نكهة في القائمة → **يُربط بها**.
2. سطر لا يطابق شيئاً → **تُنشأ له نكهة** بنفس الاسم وبنفس **حالة التوفر** (المطفأ يبقى مطفأً).
3. الاسم نفسه على منتجين → **نكهة واحدة** يشير إليها الاثنان.
4. العائلة تُؤخذ من النكهة، لا من السطر.

النكهات المُنشأة تظهر في **القائمة ← النكهات** غير مربوطة بأي منتج builder — راجعوها وأضيفوا لها الصورة والاسم الإنجليزي.

## النشر

```sh
git pull
php artisan migrate --force      # عمود النكهة + ربط الأسطر القائمة
php artisan config:clear
```

ثم من **القائمة ← المنتجات ← (المنتج) ← بوظة إضافية**: اختر النكهة، واكتب سعرها على هذا المنتج.
