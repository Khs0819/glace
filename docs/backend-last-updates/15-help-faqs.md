# 15 — صفحة المساعدة: قائمة الأسئلة الشائعة

**الأولوية:** منخفضة
**Endpoints:** `GET /help/faqs`
**الحالة الحيّة (2026-09-01):** الأسئلة ثابتة بالكامل بالكود (`src/hooks/help/fetchHelpFaqs.ts`) — نقلها هون بيسمح لفريق الدعم يعدّل الأسئلة من لوحة التحكم (Filament) بدون نشر كود جديد.

---

## شكل البيانات

```ts
interface Faq {
  id: string;
  question: string;
  /** فقرات مفصولة بـ"\n\n"؛ فقرة تبدأ بـ"- " بترندر كقائمة نقطية (كل سطر عنصر). */
  answer: string;
  /** رابط اختياري بآخر الجواب، متل رابط صفحة تواصل معنا. */
  link?: { href: string; label: string };
}
```

## `GET /help/faqs`

```json
[
  {
    "id": "how-to-order",
    "question": "كيف أقدّم طلب؟",
    "answer": "تصفّح المنيو، أضف المنتجات التي تريدها إلى السلة، ثم اختر طريقة الاستلام..."
  },
  {
    "id": "order-not-arrived",
    "question": "لسة ما وصلني طلبي أو في مشكلة، شو أعمل؟",
    "answer": "تواصل معنا مباشرةً وسيتم مساعدتك في أقرب وقت.",
    "link": { "href": "/contact", "label": "تواصل معنا" }
  }
]
```

ترتيب المصفوفة = ترتيب العرض بالصفحة. لا يوجد pagination، القائمة قصيرة (سبع أسئلة حالياً).

---

## معايير قبول

- [ ] القائمة تُدار من لوحة التحكم (Filament) — تعديل نص سؤال أو إضافة سؤال جديد بدون نشر كود
- [ ] محتوى الأسئلة مطابق للسلوك الفعلي لأنظمة الطلبات/الدفع/المحفظة وقت الكتابة (خصوصاً جوال باي آلي مقابل يدوي، وشرط ظهور زر الإلغاء)
