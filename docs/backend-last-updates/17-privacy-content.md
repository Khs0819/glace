**الأولوية:** منخفضة
**Endpoints:** `GET /privacy`
**الحالة الحيّة (2026-09-01):** الأقسام ثابتة بالكامل بالكود (`src/hooks/privacy/fetchPrivacyContent.ts`) — نقلها هون بيسمح لفريق الدعم يعدّل نص سياسة الخصوصية من لوحة التحكم (Filament) بدون نشر كود جديد. نفس النمط تماماً متل [`16-terms-content.md`](./16-terms-content.md).

---

## شكل البيانات

استجابة `GET /privacy` هي **سلسلة نصية واحدة فيها HTML كامل** (مش مصفوفة أقسام)، تحتوي كل الأقسام مع عناوينها:

```json
"<h3>1. المعلومات التي نجمعها</h3><p>...</p><ul><li>...</li></ul><h3>2. كيف نستخدم معلوماتك</h3>..."
```

- استخدم فقط: `<h3>` للعناوين، `<p>` للفقرات، `<ul><li>` للقوائم، `<a href="...">` للروابط.
- ترتيب العناصر بالـHTML = ترتيب العرض بالصفحة.
- لا يوجد pagination أو حقول إضافية — السلسلة نفسها هي كل المحتوى.

## `GET /privacy`

الأقسام الحالية التسعة: المعلومات التي نجمعها، كيف نستخدم معلوماتك، مشاركة المعلومات مع أطراف ثالثة، صور إشعارات الدفع، أمان البيانات، الاحتفاظ بالبيانات، حقوقك، التعديلات على هذه السياسة، التواصل معنا.

```json
"<h3>1. المعلومات التي نجمعها</h3><p>نقوم بجمع المعلومات...</p><h3>9. التواصل معنا</h3><p>لأي استفسار... <a href=\"/contact\">تواصل معنا</a> ...</p>"
```

## ⚠️ تنبيه أمني مهم: Sanitization

نفس التنبيه المذكور بـ[`16-terms-content.md`](./16-terms-content.md): الفرونت إند يمرّر هاد الـHTML عبر `isomorphic-dompurify` قبل `dangerouslySetInnerHTML` (`PrivacyPanel.tsx`) — إلزامي حتى لو المصدر (Filament) موثوق. رجاءً طبّقوا تنقية مماثلة بالباك اند كطبقة دفاع إضافية، مش كبديل عن تنقية الفرونت.
